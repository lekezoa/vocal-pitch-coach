## 🌟 Overview
Inspired by OnKey and Dessa, **VocalCoach AI** is a client-side web application that listens to your voice, detects fundamental musical pitch frequencies in real time, and uses Pollinations AI to provide personalized vocal feedback, vibrato scoring, and diction corrections.

## 🔑 Bring Your Own Pollen (`<polli-connect>`)
- Implements the official Pollinations `<polli-connect>` drop-in component.
- Authorizes spend directly from the user's Pollen balance.
- 100% client-side Web Audio API processing.

## 🚀 Features
- **Real-Time Pitch Detection:** Autocorrelation audio analysis displaying musical notes (C4, G#4, etc.) and Hz.
- **Visual Audio Oscilloscope:** 60 FPS live sound waveform visualizer.
- **AI Vocal Coach Critique:** Detailed suggestions on breath support, off-key detection, and pitch drift.
- **Practice Routines:** Steady note holding, speech diction, and octave range exercises.
